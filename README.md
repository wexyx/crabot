# Crabot

**把 AI 助手组成团队，让它们在不同电脑上一起工作。**

你可以先和一个助手聊天，也可以找来多个助手，让它们分工、讨论、检查彼此的工作。团队搭好后，还能作为一个整体，参与下一个任务。

Crabot 可以使用自己的助手，也可以接入 Codex、Claude。你决定要完成什么、让谁参与，它们按你设定的方式配合。

## 安装与更新

打开 macOS 或 Linux 的终端，复制执行：

```bash
curl -fsSL https://raw.githubusercontent.com/wexyx/crabot/main/install.sh | bash
```

安装完成后，新开一个终端即可使用。后续在 Crabot 对话中输入 **`/update`** 更新，已有配置和聊天记录会保留，重启 Crabot 后使用新版本。再次执行安装命令也可以更新。

可用版本见 [下载页面](https://github.com/wexyx/crabot/releases)，安装要求见 [进阶说明](docs/advanced-startup.md#系统要求)。

## 开始使用

输入：

```bash
crabot
```

第一次启动会引导你选择助手，填写所需的 AI 服务信息。配置完成后，直接告诉它你想做什么。

也可以打开终端显示的网页地址，在网页中使用。两种方式管理的是同一批助手和聊天，不需要分别设置。以后启动仍只需输入 `crabot`。

## 助手们怎样一起工作

```text
                你
                │
          终端 或 网页
                │
              Crabot
                │
       一个项目，一起完成任务
                │
      ┌─────────┼─────────┐
      ▼         ▼         ▼
   一个助手   一组助手   另一台电脑
                         上的助手
      └─────────┬─────────┘
                │
          按角色分工合作
          使用分配的工具
          在同一处查看进展
```

### 谁擅长什么，就让谁来做

一个项目可以同时使用不同的助手。例如，让 Codex 编写代码，让 Claude 检查方案，再由指定的负责人整理结果。

分工由项目安排，不绑在某一个助手身上。**换一个成员，不必把整个团队重新搭一遍；也不用为了合作，让所有人都使用同一种助手。**

### 不只是一起回答，还能按规则配合

你可以让助手轮流讨论，也可以指定一个负责人，根据成员的角色分配任务。某个助手额度不足时，还可以按预先设定的顺序交给下一个。

**把合作方式设定好，就能减少在多个聊天窗口之间来回复制内容、传递任务的工作。** 每个助手的发言仍可分别查看，方便知道谁做了什么。

### 搭好的团队，下次还能接着用

一组配合好的助手，可以被当成一个整体加入其它项目。例如，把“开发、检查、总结”组成一个团队，之后直接邀请这个团队参与更大的任务。

外面只需要给团队分配目标，团队内部继续按自己的规则合作。**已经安排好的分工可以重复使用，不必每次从头组织。**

### 先用一台电脑，需要时再连接更多电脑

每台电脑上的 Crabot 都可以独立使用，也可以主动连接其它 Crabot，在允许的范围内调用对方的助手。

不同网络中的电脑可以通过一台双方都能访问的 Crabot 传递任务，**不必让每台电脑都能被公网直接访问**。连接后，各台电脑仍然管理自己的助手和数据；不需要远端助手的任务，仍可在本地完成。

你可以从自己的一台电脑开始，有需要时再把其它电脑上的助手加入进来。

### 工具准备一次，按需要分给助手

工具让助手执行具体操作，技能告诉助手怎样完成一类任务。它们由 Crabot 集中维护，再分给需要的项目和助手。

**不用为每个助手重复维护相同的内容；换助手时，也能继续使用 Crabot 中已有的工具和技能。** 哪些可以使用、哪些需要你确认，分别控制。

### 终端和网页，共用同一套工作内容

习惯打字就用终端，希望直观看到成员和配置就打开网页。两者使用同一批助手、项目和聊天记录。

**切换使用方式，不用重新创建项目、重新配置助手，也不用维护两份设置。**

Crabot 把“选择助手、组织合作、准备工具、连接电脑”放在一起，同时让它们可以分别调整。你可以先简单使用，再逐步扩展，而不是每增加一种需要，就重新搭建一套工作方式。
